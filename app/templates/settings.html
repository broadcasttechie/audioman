Root folder -- where Inbox/Library get looked for. Only matters if they're nested inside a shared parent rather than at the top level this connection sees.

Recommended: service account. OAuth (below) grants access to your whole Drive -- there's no per-folder scope. A service account only ever sees folders explicitly shared with it, which is genuine restriction, not just convention.

  1. Google Cloud Console -> IAM & Admin -> Service Accounts -> Create Service Account (no roles needed)
  2. Open it -> Keys -> Add Key -> Create new key -> JSON (downloads a file)
  3. In Google Drive, share your Inbox and Library folders with the service account's email (looks like name@project.iam.gserviceaccount.com), Editor access
  4. Paste the downloaded JSON file's contents below
